# Width changes that preserve the gate box

The saved 15-site graphene fixture admits **0.10, 0.11 and 0.119 nm** Gaussian widths on both original grids. These provide same-box sensitivity cases. Refining the mesh does **not** make a 0.12 nm cloud admissible: its five-sigma support touches an electrode.

| Gaussian sigma (nm) | 0.10 nm spacing | 0.05 nm spacing |
|---|---|---|
| 0.05 | Underresolved by configured rule | Admissible |
| 0.08 | Underresolved by configured rule | Admissible |
| 0.10 | Admissible | Admissible |
| 0.11 | Admissible | Admissible |
| 0.119 | Admissible | Admissible |
| 0.12 | Electrode overlap | Electrode overlap |
| 0.13 | Support outside box | Support outside box |

All eight admitted cases conserve the sum of 15 unit test charges within relative tolerance 1e-12. These are normalized numerical test charges, not computed electron occupations. Coordinates and meshes come directly from the preserved finite-width feedback result; input and code hashes accompany the audit.

Reproduce: `python -m physics_layers.width_domain_audit`. The script refuses to overwrite its result. No Kwant solve is needed.

Admissibility only establishes compatibility with the implemented support and resolution rules. It does not establish convergence, a calibrated carbon-orbital width, current sensitivity, or physical validation. In particular, one mesh interval per sigma passes the current rule but still needs refinement checks. No transport result was generated by this audit.
