# Conventional detector targets

Primary engineering comparator: commercially available zero-bias Schottky
detectors, rather than only our synthetic geometry controls.

Source: [Virginia Diodes manufacturer table](https://vadiodes.com/detectors-zbd/),
retrieved October 22, 2026. Values are typical specifications, not guaranteed
limits. Responsivity depends on RF input power. Response rate applies to the fast
configuration only; RF carrier band and output response rate are distinct.

| Proposed target | RF band | Typical response | Typical NEP | Maximum output response rate |
| --- | --- | --- | --- | --- |
| WR10, ZBD-F configuration | 75–110 GHz | 2300 V/W | 3.5 pW/√Hz | approximately 15 GHz |
| WR3.4, ZBD-F configuration | 220–330 GHz | 1700 V/W | 4.8 pW/√Hz | approximately 40 GHz |

These are reference targets, not completed matched comparisons. Freeze exact
temperature, input-power reference plane, output load, modulation frequency,
readout noise and usable input range from the selected product characterization
before defining an acceptance threshold. Missing conditions remain unresolved.

The present graphene estimate of 1.24 pW/√Hz is an equilibrium, quasistatic
electrical-terminal calculation. It does not establish superiority over either
product: antenna/matching loss, carrier-frequency response, driven and amplifier
noise, electrostatic feedback and manufacturing robustness are not included.

Application qualification should require one material advantage (sensitivity,
bandwidth, dynamic range or integration footprint) while satisfying the other
frozen requirements. Maintain separate archives for distinct applications. An
improvement at one unmatched operating point cannot satisfy the acceptance gate.
